Why vague prompts add up

A chat model doesn't remember your conversation the way a person does. On every new message it re-reads everything said so far. Drag the slider to see what each "no, I meant…" costs.

Message 1Text the model re-reads on each message

This is an illustration, not a measurement. It assumes about 200 words per exchange. Some providers cache repeated text, which lowers the cost of re-reading but does not remove it. Either way, one clear prompt beats a long back-and-forth.

For teachers and librarians

Use Green AI Bingo as a 20-minute climate and digital-literacy activity for Grades 6–12, or set it out on a library table. Free to print and share, with no sign-up.

Warm-up (5 min)

Ask the class: "Where does an AI answer actually come from?" List guesses, then show the "One prompt's footprint" and "BC grid vs. the cloud" squares.

Play (10 min)

In pairs, students open a square, read the "why," and decide which habits they already have. Then run the Lightning round together as a class.

Reflect (5 min)

Each student commits to one habit for the week. This connects to the First Peoples Principle of Learning: "Learning involves recognizing the consequences of one's actions."

Sources and honesty notes

A single text prompt uses very little energy. The impact comes from scale (billions of prompts a day) and from the heaviest uses: large models, reasoning modes, images and video. These habits target the heaviest uses. Squares marked How it works explain how AI systems work in general; squares marked Sourced cite the figures below.
