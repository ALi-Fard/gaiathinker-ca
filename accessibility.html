Accessibility Statement

Last reviewed: July 2026  ·  GaiaLink Intelligence Systems Inc.

Our commitment: GaiaThinker is committed to WCAG 2.1 Level AA conformance. Accessibility is a product requirement, not an afterthought — all new features are reviewed against WCAG criteria before release.

1. Our Commitment

GaiaLink Intelligence Systems Inc. is committed to making GaiaThinker accessible to all students and educators, including those with disabilities. We design in alignment with the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA standard, and with Microsoft's Accessibility Design Principles, which inform the Fluent Design System used throughout our platform.

As an AI platform for British Columbia schools, we recognize that students with a wide range of abilities — visual, auditory, motor, and cognitive — will use GaiaThinker. All students deserve equal access to climate literacy education.

2. Conformance Status

GaiaThinker is currently in partial conformance with WCAG 2.1 Level AA. We are an early-stage product and some non-conformances exist; they are listed below under Known Limitations.

Passes
Keyboard navigation
All primary navigation, menus, and forms are operable via keyboard alone.
Passes
Colour contrast
All text meets WCAG 2.1 AA contrast ratios (4.5:1 for normal text, 3:1 for large text).
Passes
Text resize
All content remains readable and functional at 200% browser zoom without horizontal scrolling.
Passes
Link purpose
All links have descriptive text. No "click here" or ambiguous link labels.
Passes

All form fields have explicit labels. Error messages are descriptive and programmatically associated.
In Progress
Screen reader support
Core pages pass. AI tutor session views are being updated for full ARIA landmark coverage.

3. Microsoft Accessibility Alignment

GaiaThinker is built on Microsoft's Fluent Design System, which embeds accessibility as a core principle. Our AI component (Professor Ember) runs on Azure OpenAI Service, which is covered by Microsoft's Accessibility Conformance Report. Where applicable, we inherit accessibility assurances from the Microsoft platform layer.

  • Fluent Design tokens ensure consistent focus indicators across all interactive elements
  • Colour system uses Microsoft's neutral and semantic palette, validated for contrast compliance
  • Microsoft Teams integration (roadmap) will inherit Teams' WCAG AA certification

4. Known Limitations

The following limitations exist in the current version. We are actively working to resolve them:

  • AI tutor session — ARIA live regions: Professor Ember's real-time responses are not yet announced via ARIA live regions to all screen readers. Targeted for resolution in Q3 2026.
  • Data visualizations: Climate data charts currently lack text alternatives. Alt text and data table equivalents are in development.
  • PDF resources: Some linked third-party curriculum resources (external PDFs) may not be fully accessible. We are auditing and replacing where possible.

5. Supported Assistive Technologies

GaiaThinker has been tested with the following assistive technologies:

  • NVDA + Google Chrome (Windows)
  • VoiceOver + Safari (macOS / iPad)
  • Windows Narrator + Microsoft Edge
  • Keyboard-only navigation (Tab, Shift+Tab, Enter, Space, Arrow keys)

GaiaThinker is designed to work on school-issued devices including Chromebooks, iPad, and Windows computers without requiring additional software installation.

6. Requesting Accommodations

If you or a student need an accommodation that GaiaThinker does not currently support, please contact us. We respond to accessibility requests within two business days.
